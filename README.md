# Northstar Store — React E-commerce Storefront

A portfolio-ready e-commerce storefront built with React, TypeScript and Redux Toolkit.

## Highlights
- Responsive product catalogue
- Search and category filtering
- Product detail pages
- Redux Toolkit cart state
- Quantity management and order summary
- Checkout flow with success state
- Reusable product components
- Loading/error/empty-state patterns
- Accessible labels and semantic HTML

## Stack
React + TypeScript + Vite + Redux Toolkit + React Router + Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
